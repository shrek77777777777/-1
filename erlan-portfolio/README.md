# Erlan Portfolio

Минималистичный сайт-портфолио на React + Vite.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий с названием `erlan-portfolio`.
2. Загрузите содержимое архива в корень репозитория (папки `src` и `.github` тоже должны быть в корне).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: GitHub Actions.
5. Откройте вкладку Actions и дождитесь завершения workflow.
6. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/erlan-portfolio/`.

Перед сдачей проверьте данные об образовании, проектах и замените email `your-email@example.com` в `src/App.jsx`.
